오늘은 **Bootstrap을 이용해서 Navbar와 서브메뉴를 만드는 방법**을 배웠다.

그리고 JavaScript보다 코드를 간단하게 작성할 수 있는 **jQuery**에 대해서도 알아보았다.

추가로 CSS의 `transition`을 이용해서 **간단한 애니메이션 효과를 만드는 방법**도 배웠다.

이번 포스팅에서는 오늘 배운 내용을 하나씩 정리해보자.

---

# 1. Bootstrap Navbar 만들기

먼저 Bootstrap을 이용해서 간단한 Navbar를 만들어보았다.

```html
<nav class="navbar navbar-light bg-light">
  <div class="container-fluid">
    <span class="navbar-brand">Navbar</span>

    <button class="navbar-toggler" type="button">
      <span class="navbar-toggler-icon"></span>
    </button>
  </div>
</nav>
```

Bootstrap에서 제공하는 클래스를 사용하면 Navbar의 기본적인 디자인을 쉽게 만들 수 있다.

여기서 중요한 부분은 다음 버튼이다.

```html
<button class="navbar-toggler" type="button">
  <span class="navbar-toggler-icon"></span>
</button>
```

이 버튼을 클릭했을 때 아래에 있는 서브메뉴가 나타나도록 만들어보자.

---

# 2. 서브메뉴 만들기

서브메뉴는 Bootstrap에서 제공하는 `list-group`을 이용해서 만들어보았다.

```html
<ul class="list-group">
  <li class="list-group-item">An item</li>
  <li class="list-group-item">A second item</li>
  <li class="list-group-item">A third item</li>
  <li class="list-group-item">A fourth item</li>
  <li class="list-group-item">And a fifth one</li>
</ul>
```

이제 처음에는 서브메뉴가 접혀 있도록 CSS를 작성한다.

```css
.list-group {
  max-height: 0;
  overflow: hidden;
}
```

여기서 중요한 것은 `max-height`와 `overflow`이다.

`max-height: 0`

서브메뉴의 최대 높이를 `0px`로 설정한다.

```css
max-height: 0;
```

따라서 서브메뉴가 처음에는 접혀 있는 것처럼 보인다.

`overflow: hidden`

그런데 높이를 `0px`로 설정했다고 해서 내부의 내용이 무조건 보이지 않는 것은 아니다.

이때

```css
overflow: hidden;
```

을 사용하면 해당 영역을 넘어가는 내용이 보이지 않게 된다.

따라서

```css
.list-group {
  max-height: 0;
  overflow: hidden;
}
```

을 작성하면 서브메뉴가 접힌 상태가 된다.

---

# 3. `show` 클래스를 이용해서 메뉴 열기

이제 메뉴가 열렸을 때 적용할 CSS를 만들어준다.

```css
.show {
  max-height: 400px;
}
```

기본 상태에서는

```css
.list-group {
  max-height: 0;
  overflow: hidden;
}
```

이지만,

`show` 클래스가 추가되면

```css
.show {
  max-height: 400px;
}
```

가 적용된다.

즉,

```text
max-height: 0px
      ↓
show 클래스 추가
      ↓
max-height: 400px
```

이렇게 서브메뉴의 높이가 변경된다.

---

# 4. JavaScript로 `show` 클래스 추가하기

이제 Navbar 버튼을 클릭했을 때 `show` 클래스를 추가하면 된다.

JavaScript를 이용하면 다음과 같이 작성할 수 있다.

```javascript
document
  .querySelector(".navbar-toggler")
  .addEventListener("click", function () {
    document.querySelector(".list-group").classList.toggle("show");
  });
```

여기서 핵심은

```javascript
classList.toggle("show");
```

이다.

`toggle()`은 클래스가 없으면 추가하고, 클래스가 있으면 제거한다.

따라서 버튼을 클릭할 때마다

```text
show 없음
   ↓
show 추가
   ↓
메뉴 열림
```

그리고 다시 클릭하면

```text
show 있음
   ↓
show 제거
   ↓
메뉴 닫힘
```

이 된다.

---

# 5. jQuery를 이용해서 코드 간단하게 만들기

같은 기능을 jQuery를 사용하면 더 간단하게 작성할 수 있다.

먼저 jQuery를 HTML에 연결한다.

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/jquery/3.6.0/jquery.min.js"></script>
```

그리고 다음과 같이 작성한다.

```javascript
$(".navbar-toggler").on("click", function () {
  $(".list-group").toggleClass("show");
});
```

JavaScript와 비교해보면 코드가 훨씬 짧아진 것을 확인할 수 있다.

### JavaScript

```javascript
document
  .querySelector(".navbar-toggler")
  .addEventListener("click", function () {
    document.querySelector(".list-group").classList.toggle("show");
  });
```

### jQuery

```javascript
$(".navbar-toggler").on("click", function () {
  $(".list-group").toggleClass("show");
});
```

jQuery에서는

```javascript
document.querySelector();
```

대신

```javascript
$();
```

를 사용할 수 있다.

그리고

```javascript
addEventListener();
```

대신

```javascript
.on()
```

을 사용할 수 있다.

또한

```javascript
classList.toggle();
```

대신

```javascript
toggleClass();
```

를 사용한다.

---

# 6. jQuery 기본 문법 정리

이번에 배운 내용을 간단하게 정리하면 다음과 같다.

| JavaScript                 | jQuery           |
| -------------------------- | ---------------- |
| `document.querySelector()` | `$()`            |
| `addEventListener()`       | `.on()`          |
| `classList.add()`          | `.addClass()`    |
| `classList.remove()`       | `.removeClass()` |
| `classList.toggle()`       | `.toggleClass()` |

예를 들어 JavaScript에서

```javascript
document.querySelector("#login");
```

이라고 작성했다면 jQuery에서는

```javascript
$("#login");
```

으로 작성할 수 있다.

클래스를 선택할 때도

```javascript
$(".list-group");
```

처럼 `$()` 안에 CSS 선택자를 넣어주면 된다.

---

# 7. 로그인 모달 만들기

이번에는 로그인 버튼을 클릭하면 모달창이 나타나도록 만들어보았다.

HTML은 다음과 같다.

```html
<button id="login">로그인</button>

<div class="black-bg">
  <div class="white-bg">
    <h4>로그인하세요</h4>

    <button class="btn btn-danger" id="close">닫기</button>
  </div>
</div>
```

먼저 모달창이 처음에는 보이지 않도록 CSS를 작성한다.

```css
.black-bg {
  visibility: hidden;
  transition: all 1s;
  width: 100%;
  height: 100%;
  position: fixed;
  background: rgba(0, 0, 0, 0.5);
  z-index: 5;
  padding: 30px;
  opacity: 0;
}
```

그리고 모달창을 보여줄 때 사용할 클래스를 만든다.

```css
.show-modal {
  visibility: visible;
  opacity: 1;
}
```

---

# 8. 로그인 버튼을 클릭하면 클래스 추가

jQuery를 이용하면 다음과 같이 작성할 수 있다.

```javascript
$("#login").on("click", function () {
  $(".black-bg").addClass("show-modal");
});
```

로그인 버튼을 클릭하면

```javascript
$(".black-bg");
```

에

```text
show-modal
```

클래스가 추가된다.

그러면

```css
.show-modal {
  visibility: visible;
}
```

이 적용되면서 모달창이 나타난다.

---

# 9. 닫기 버튼을 클릭하면 클래스 제거

닫기 버튼에서는 반대로 클래스를 제거한다.

```javascript
$("#close").on("click", function () {
  $(".black-bg").removeClass("show-modal");
});
```

결과적으로 다음과 같은 구조가 만들어진다.

```text
로그인 버튼 클릭
      ↓
show-modal 추가
      ↓
모달창 나타남

닫기 버튼 클릭
      ↓
show-modal 제거
      ↓
모달창 사라짐
```

# 10. CSS 애니메이션의 기본 원리

이번에는 CSS의 `transition`을 이용해서 애니메이션을 만드는 방법을 배웠다.

**A 상태에서 B 상태로 움직이는 one-way 애니메이션**은 기본적으로 다음 순서로 만들 수 있다.

### ① 시작 스타일 만들기

먼저 시작 상태를 만든다.

```css
.list-group {
  max-height: 0;
  overflow: hidden;
}
```

현재 서브메뉴의 높이는 `0px`이다.

---

### ② 최종 스타일 만들기

다음으로 최종 상태를 만든다.

```css
.show {
  max-height: 400px;
}
```

`show` 클래스가 추가되면 높이가 `400px`까지 늘어난다.

---

### ③ JavaScript로 최종 스타일 적용하기

이제 JavaScript를 이용해서 `show` 클래스를 추가한다.

```javascript
$(".list-group").addClass("show");
```

또는 열고 닫기를 모두 구현하려면

```javascript
$(".list-group").toggleClass("show");
```

를 사용하면 된다.

---

### ④ 시작 스타일에 `transition` 추가

마지막으로 변화가 부드럽게 일어나도록 `transition`을 추가한다.

```css
.list-group {
  max-height: 0;
  overflow: hidden;
  transition: max-height 0.5s;
}
```

그러면

```text
max-height: 0px
       ↓
   0.5초 동안 변화
       ↓
max-height: 400px
```

처럼 높이가 갑자기 변하지 않고 부드럽게 변한다.

---

# 11. One-way 애니메이션 정리

이번에 배운 **one-way 일방향 애니메이션**의 가장 기본적인 구조는 다음과 같다.

```text
1. 시작 스타일 만들기
        ↓
2. 최종 스타일 만들기
        ↓
3. JavaScript로 최종 스타일 적용
        ↓
4. 시작 스타일에 transition 추가
```

예를 들어 서브메뉴를 만든다면 다음과 같다.

```css
/* 시작 상태 */
.list-group {
  max-height: 0;
  overflow: hidden;
  transition: max-height 0.5s;
}

/* 최종 상태 */
.show {
  max-height: 400px;
}
```

그리고 JavaScript에서

```javascript
$(".list-group").toggleClass("show");
```

를 실행한다.

그러면

```text
닫힘
max-height: 0px

      ↓

show 클래스 추가

      ↓

열림
max-height: 400px
```

으로 변화한다.

---

# 12. 전체 CSS 코드

이번에 작성한 서브메뉴와 모달창의 CSS를 합치면 다음과 같다.

```css
.list-group {
  max-height: 0;
  overflow: hidden;
  transition: max-height 0.5s;
}

.show {
  max-height: 400px;
}

.black-bg {
  visibility: hidden;
  transition: all 1s;
  width: 100%;
  height: 100%;
  position: fixed;
  background: rgba(0, 0, 0, 0.5);
  z-index: 5;
  padding: 30px;
  opacity: 0;
}
.white-bg {
  background: white;
  border-radius: 5px;
  padding: 30px;
}

.show-modal {
  visibility: visible;
  opacity: 1;
}
```

# 마무리

오늘 배운 내용을 정리하면 크게 3가지이다.

### 1. Bootstrap Navbar

Bootstrap에서 제공하는 리클래스를 이용하면 Navbar와 스트 같은 UI를 쉽게 만들 수 있다.

### 2. jQuery

jQuery를 사용하면 JavaScript에서 반복적으로 작성해야 하는 코드를 더욱 간단하게 작성할 수 있다.

```javascript
$(".list-group").toggleClass("show");
```

### 3. CSS 애니메이션

A 상태에서 B 상태로 변화하는 가장 기본적인 애니메이션은

```text
1. 시작 스타일 만들기
2. 최종 스타일 만들기
3. JS로 최종 스타일 적용
4. transition 추가
```

의 순서로 만들 수 있다.

특히 이번에 배운

```javascript
toggleClass();
```

와

```css
transition
```

을 이용하면 앞으로 **서브메뉴, 모달창, 드롭다운 등 다양한 UI 효과**를 만들 수 있다.
