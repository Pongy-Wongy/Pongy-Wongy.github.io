# JavaScript 파라미터 문법

JavaScript를 공부하면서 함수에 값을 전달할 때 사용하는 **파라미터(Parameter)** 문법을 연습해봤다.

이번에는 버튼을 클릭했을 때 함수에 원하는 값을 전달해서

- 이름 변경
- 글자 크기 및 색상 변경
- 알림창 내용 변경

을 만들어봤다.

---

## 1. 파라미터(Parameter)란?

먼저 파라미터는 **함수에 값을 전달하기 위해 사용하는 변수**라고 생각하면 된다.

파라미터라고 하면 어려우니까 구멍이라고 하자.

함수내에 구멍을 만든다.

예를 들어 다음과 같은 함수가 있다.

```javascript
function 함수작명(구멍) {
  document.getElementById("name").innerHTML = 구멍;
}
```

여기서 `구멍`이 파라미터이다.

그리고 함수를 호출할 때 원하는 값을 넣어준다.

```javascript
함수작명("김철수");
```

그러면

```text
구멍 = "김철수"
```

가 되어 함수 내부에서 사용할 수 있다.

즉,

```javascript
function 함수작명(구멍) {
  // 구멍을 사용
}

함수작명("김철수");
```

의 관계는 다음과 같다.

```text
함수의 파라미터(구멍)
      ↓
    구멍

전달하는 값
      ↓
  "김철수"
```

---

## 2. 이름 변경하기

HTML에 이름을 표시할 `<h3>` 태그를 만들었다.

```html
<h3 id="name">홍길동</h3>

<button onclick="이름변경('김철수')">이름변경</button>
```

버튼을 클릭하면 `이름변경()` 함수가 실행되고 `"김철수"`라는 값을 전달한다.

JavaScript는 다음과 같이 작성했다.

```javascript
function 이름변경(새이름) {
  document.getElementById("name").innerHTML = 새이름;
}
```

### 동작 과정

버튼 클릭

```javascript
이름변경("김철수");
```

↓

함수 실행

```javascript
function 이름변경(새이름)
```

↓

`새이름`에 `"김철수"`가 들어감

↓

```javascript
document.getElementById("name").innerHTML = 새이름;
```

↓

화면의 `홍길동`이 `김철수`로 변경된다.

---

## 3. 여러 개의 파라미터 사용하기

파라미터는 하나만 사용할 필요가 없다.

여러 개의 값을 전달할 수도 있다.

이번에는 글자의

- 크기
- 내용
- 색상

을 한 번에 변경해보았다.

```html
<h3 id="text">글자크기</h3>

<button onclick="글자변경('12px', '글자크기작게', 'blue')">작게</button>

<button onclick="글자변경('30px', '글자크기크게', 'red')">크게</button>
```

JavaScript에서는 파라미터를 3개 만들었다.

```javascript
function 글자변경(구멍, 구멍2, 구멍3) {
  document.querySelector("#text").style.fontSize = 구멍;
  document.querySelector("#text").innerHTML = 구멍2;
  document.querySelector("#text").style.color = 구멍3;
}
```

처음에는 `구멍`, `구멍2`, `구멍3`처럼 이름을 지었지만 실제 개발에서는 의미가 잘 드러나는 이름을 사용하는 것이 좋다.

예를 들어 다음과 같이 작성할 수 있다.

```javascript
function 글자변경(크기, 내용, 색상) {
  document.querySelector("#text").style.fontSize = 크기;
  document.querySelector("#text").innerHTML = 내용;
  document.querySelector("#text").style.color = 색상;
}
```

---

## 4. 여러 파라미터가 전달되는 과정

다음 코드를 보면

```javascript
글자변경("12px", "글자크기작게", "blue");
```

함수의 파라미터 순서대로 값이 들어간다.

```javascript
function 글자변경(크기, 내용, 색상)
```

따라서 다음과 같이 연결된다.

| 파라미터 | 전달되는 값      |
| -------- | ---------------- |
| `크기`   | `"12px"`         |
| `내용`   | `"글자크기작게"` |
| `색상`   | `"blue"`         |

결과적으로 함수 내부에서는

```javascript
크기 = "12px";
내용 = "글자크기작게";
색상 = "blue";
```

처럼 사용할 수 있다.

## 5. 알림창 만들기

이번에는 파라미터를 이용해서 알림창의 **화면 표시 여부와 메시지**를 변경해봤다.

HTML은 다음과 같이 작성했다.

```html
<div class="alert-box" id="alert">
  <p>알림창임</p>

  <button onclick="창버튼('none')">닫기</button>
</div>

<button onclick="창버튼('block', '아이디를 입력하세요')">아이디</button>

<button onclick="창버튼('block', '비밀번호를 입력하세요')">비번</button>
```

JavaScript는 다음과 같다.

```javascript
function 창버튼(구멍, 구멍2) {
  document.querySelector(".alert-box").style.display = 구멍;
  document.querySelector(".alert-box p").innerHTML = 구멍2;
}
```

여기서는 파라미터를 2개 사용했다.

```javascript
function 창버튼(구멍, 구멍2)
```

첫 번째 파라미터는 `display`를 변경하고,

두 번째 파라미터는 알림창의 내용을 변경한다.

---

## 6. 아이디 버튼을 클릭하면?

다음 버튼을 클릭하면

```html
<button onclick="창버튼('block', '아이디를 입력하세요')">아이디</button>
```

다음과 같은 값이 함수에 전달된다.

```text
구멍  → "block"
구멍2 → "아이디를 입력하세요"
```

따라서 실제로는 다음과 같이 동작한다.

```javascript
document.querySelector(".alert-box").style.display = "block";

document.querySelector(".alert-box p").innerHTML = "아이디를 입력하세요";
```

결과적으로 알림창이 나타나고

> 아이디를 입력하세요

라는 메시지가 표시된다.

---

## 7. 비밀번호 버튼을 클릭하면?

이번에는

```html
<button onclick="창버튼('block', '비밀번호를 입력하세요')">비번</button>
```

을 클릭한다.

이번에는

```text
구멍  → "block"
구멍2 → "비밀번호를 입력하세요"
```

가 전달된다.

따라서 알림창에는

> 비밀번호를 입력하세요

가 표시된다.

같은 함수 `창버튼()`을 사용하지만 **전달하는 파라미터의 값만 변경해서 서로 다른 동작을 만들 수 있다.**

---

## 8. 닫기 버튼에서는 파라미터를 하나만 전달

닫기 버튼은 다음과 같다.

```html
<button onclick="창버튼('none')">닫기</button>
```

여기서는 파라미터를 하나만 전달했다.

```javascript
창버튼("none");
```

그러면

```text
구멍 = "none"
구멍2 = undefined
```

가 된다.

그래서 다음 코드가 실행된다.

```javascript
document.querySelector(".alert-box").style.display = "none";
```

알림창이 사라진다.

다만 현재 코드에서는 `구멍2`가 전달되지 않았기 때문에

```javascript
document.querySelector(".alert-box p").innerHTML = 구멍2;
```

부분에서 기존 메시지가 `undefined`로 변경될 수 있다.

따라서 실제로는 다음처럼 조건을 추가하는 방법도 있다.

```javascript
function 창버튼(display, message) {
  document.querySelector(".alert-box").style.display = display;

  if (message) {
    document.querySelector(".alert-box p").innerHTML = message;
  }
}
```

이렇게 하면 닫을 때 메시지를 전달하지 않아도 기존 메시지를 유지할 수 있다.

## 10. 오늘 배운 핵심

이번 예제에서 가장 중요한 것은 **함수에 값을 전달하는 방법**이다.

### 기본 형태

```javascript
function 함수이름(파라미터) {
  // 파라미터 사용
}
```

함수를 호출할 때 값을 전달한다.

```javascript
함수이름("전달할 값");
```

### 여러 개를 전달할 수도 있다.

```javascript
function 함수이름(파라미터1, 파라미터2, 파라미터3) {}
```

```javascript
함수이름("값1", "값2", "값3");
```

**순서대로 파라미터에 값이 들어간다.**

```text
파라미터1 ← 값1
파라미터2 ← 값2
파라미터3 ← 값3
```

결국 파라미터를 사용하면 **하나의 함수를 만들어 놓고 전달하는 값에 따라 다양한 동작을 수행하도록 만들 수 있다.**

이번 예제에서는 같은 `창버튼()` 함수를 사용하면서

```javascript
창버튼("block", "아이디를 입력하세요");

창버튼("block", "비밀번호를 입력하세요");

창버튼("none");
```

처럼 전달하는 값만 바꿔서 서로 다른 결과를 만들었다.

---

## 11. 한 줄 정리

> **파라미터(Parameter)는 함수를 호출할 때 전달한 값을 함수 내부에서 사용할 수 있도록 해주는 문법이다.**
