## 1. 다크모드 구현하기

### CSS로 다크모드 스타일 정의하기

CSS 클래스를 이용하면 특정 요소에 클래스를 추가하거나 제거하는 방식으로 다크모드를 구현할 수 있다.

```css
/* 다크모드 */
.dark-mode {
  background-color: #222;
  color: white;
}

/* 다크모드일 때 메뉴 */
.dark-mode .navbar {
  background-color: #333 !important;
}

/* 다크모드일 때 서브메뉴 */
.dark-mode .list-group-item {
  background-color: #333;
  color: white;
  border-color: #535;
}

/* 다크모드일 때 로그인 버튼 */
.dark-mode #login {
  background-color: #444;
  color: white;
  border: 1px solid #777;
}
```

`body`에 `dark-mode` 클래스가 추가되면 해당 요소와 내부 요소에 정의된 스타일이 적용된다.

### jQuery로 다크모드 전환하기

```javascript
$("#dark-mode-btn").on("click", function () {
  $("body").toggleClass("dark-mode");

  if ($("body").hasClass("dark-mode")) {
    $("#dark-mode-btn").html("Light 🔄");
    $("#dark-mode-btn").removeClass("bg-dark");
    $("#dark-mode-btn").addClass("bg-light text-dark");
  } else {
    $("#dark-mode-btn").html("Dark 🔄");
    $("#dark-mode-btn").removeClass("bg-light text-dark");
    $("#dark-mode-btn").addClass("bg-dark");
  }
});
```

- `.on("click", function() {})` : 클릭 이벤트 등록
- `.toggleClass()` : 클래스가 있으면 제거하고 없으면 추가
- `.hasClass()` : 특정 클래스가 존재하는지 확인
- `.addClass()` : 클래스 추가
- `.removeClass()` : 클래스 제거
- `.html()` : 요소 내부의 HTML 변경

버튼을 클릭하면 `body`의 `dark-mode` 클래스가 전환된다. 이후 `hasClass()`로 현재 모드를 확인하여 버튼의 문구와 색상을 변경한다.

## 2. JavaScript 변수란?

변수는 데이터를 저장하고 필요할 때 다시 사용할 수 있도록 해주는 기능이다.

```javascript
var 이름 = "kim";

이름 = "park";

console.log(이름); // park
```

변수를 사용하면 데이터를 간단한 이름으로 관리하고, 필요한 곳에서 값을 재사용할 수 있다.

- **선언:** 변수를 만드는 것
- **초기화:** 변수를 선언하면서 처음 값을 지정하는 것
- **재할당:** 이미 선언된 변수에 새로운 값을 넣는 것

## 3. var, let, const의 차이

### var

`var`는 같은 범위에서 재선언할 수 있고, 값을 재할당할 수도 있다.

```javascript
var 과일 = "사과";
var 과일 = "배";

console.log(과일); // 배
```

동일한 이름으로 다시 선언해도 오류가 발생하지 않을 수 있으므로 변수 관리에 주의해야 한다.

### let

`let`은 재할당이 가능하지만 같은 범위에서 재선언할 수 없다.

```javascript
let 과일 = "사과";

과일 = "배";

console.log(과일); // 배
```

다음과 같이 동일한 범위에서 같은 이름을 다시 선언하면 오류가 발생한다.

```javascript
let 과일 = "사과";
let 과일 = "배"; // SyntaxError
```

### const

`const`는 선언할 때 값을 지정해야 하며, 재선언과 재할당이 불가능하다.

```javascript
const 우유 = "초코";

우유 = "바나나"; // TypeError
```

값이 변경되지 않아야 하는 변수에 사용하면 좋다. 단, `const`로 선언한 객체나 배열은 내부 속성이나 요소를 변경할 수 있다.

## 4. var, let, const 비교

| 구분 | var | let | const |
| --- | --- | --- | --- |
| 재선언 | 가능 | 불가능 | 불가능 |
| 재할당 | 가능 | 가능 | 불가능 |
| 유효 범위 | 함수 범위 | 블록 범위 | 블록 범위 |
| 초기값 없이 선언 | 가능 | 가능 | 불가능 |

새로운 코드를 작성할 때는 기본적으로 `const`를 사용하고, 값이 변경되어야 하는 경우 `let`을 사용하는 것이 좋다.

## 5. 변수의 유효 범위(Scope)

변수의 유효 범위는 변수를 사용할 수 있는 범위를 의미한다.

```javascript
function 함수() {
  var 커피 = "아아";
}

console.log(커피); // ReferenceError
```

`커피`는 함수 내부에서 선언한 지역 변수이므로 함수 외부에서는 사용할 수 없다.

또한 `let`과 `const`는 블록 범위를 가진다.

```javascript
if (true) {
  let 과일 = "사과";
  const 음료 = "우유";
}

console.log(과일); // ReferenceError
console.log(음료); // ReferenceError
```

변수를 사용할 때는 선언한 위치와 유효 범위를 확인해야 한다.

## 6. 자주 발생하는 오류

### Assignment to constant variable

```javascript
const 우유 = "초코";
우유 = "바나나";
```

`const`로 선언한 변수에 새로운 값을 할당했을 때 발생하는 오류다. 값이 변경되어야 한다면 `let`을 사용한다.

### Identifier has already been declared

```javascript
let 과일 = "사과";
let 과일 = "배";
```

같은 범위에서 이미 선언된 변수 이름을 다시 선언했을 때 발생한다. 기존 변수에 값을 변경하려는 경우에는 재선언 대신 재할당한다.

### ReferenceError

```javascript
function 함수() {
  var 커피 = "아아";
}

console.log(커피);
```

함수 내부에서 선언한 지역 변수를 함수 외부에서 사용했기 때문에 발생한다.

## 7. 오늘 배운 내용 요약

오늘은 CSS와 jQuery를 이용해 다크모드를 구현하고, `var`, `let`, `const`의 차이점을 공부했다.

- `toggleClass()`를 이용해 다크모드를 전환할 수 있다.
- `hasClass()`를 이용해 현재 다크모드 적용 여부를 확인할 수 있다.
- `var`는 재선언과 재할당이 가능하다.
- `let`은 재할당이 가능하지만 같은 범위에서 재선언할 수 없다.
- `const`는 재선언과 재할당이 불가능하다.
- 변수의 유효 범위를 이해하면 `ReferenceError`와 같은 오류를 예방할 수 있다.

앞으로도 오늘 배운 문법을 활용해 다양한 웹 페이지 기능을 직접 구현해 보면서 JavaScript의 기본 개념을 익혀야겠다.
