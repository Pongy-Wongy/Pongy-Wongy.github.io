**## JavaScript 이벤트 리스너**

JavaScript에서는 버튼을 클릭했을 때 특정 기능을 실행하거나

마우스를 올렸을 때 동작을 실행하는 등 다양한 이벤트를 처리할 수 있다.

이전에는 HTML의 `onclick` 속성을 사용해서 버튼 클릭 이벤트를 처리했다.

예를 들어

```html
<button onclick="창버튼('none')">닫기</button>
```

처럼 작성할 수 있다.

하지만 JavaScript에서는 HTML에 `onclick`을 직접 작성하지 않고

**`addEventListener()`**를 사용해서 이벤트를 처리할 수도 있다.

---

**## onclick 대신 addEventListener 사용하기**

먼저 HTML에서 버튼에 `id`를 만들어준다.

```html
<div class="alert-box" id="alert">
  <p>알림창임</p>

  <button id="close">닫기</button>
</div>
```

이전에는

```html
<button onclick="창버튼('none')">닫기</button>
```

처럼 HTML 안에 JavaScript 코드를 작성했다.

하지만 이번에는

```html
<button id="close">닫기</button>
```

처럼 버튼에 `id`만 지정한다.

그리고 JavaScript에서 버튼을 가져온다.

```javascript
document.getElementById("close");
```

이제 `addEventListener()`를 사용해서 클릭 이벤트를 추가할 수 있다.

```javascript
document.getElementById("close").addEventListener("click", function () {});
```

---

**## addEventListener()란?**

`addEventListener()`는 HTML 요소에 **이벤트를 등록하는 기능**이다.

기본적인 형태는 다음과 같다.

```javascript
요소.addEventListener("이벤트", 실행할함수);
```

예를 들어

```javascript
document.getElementById("close").addEventListener("click", function () {});
```

에서

```text
"click"
```

은 버튼을 클릭했을 때 발생하는 이벤트이다.

즉,

```javascript
addEventListener("click", ...)
```

이라고 작성하면

> 이 요소가 클릭되었을 때 뒤에 있는 함수를 실행해라

라는 의미이다.

---

**## 클릭했을 때 알림창 닫기**

이제 실제로 버튼을 클릭했을 때 알림창이 사라지도록 만들어보자.

```javascript
document.getElementById("close").addEventListener("click", function () {
  document.querySelector(".alert-box").style.display = "none";
});
```

코드를 하나씩 살펴보면

먼저

```javascript
document.getElementById("close");
```

를 이용해서 `id="close"`인 버튼을 가져온다.

그리고

```javascript
.addEventListener("click", ...)
```

을 이용해서 버튼에 클릭 이벤트를 등록한다.

마지막으로

```javascript
document.querySelector(".alert-box").style.display = "none";
```

을 실행해서 알림창을 화면에서 숨긴다.

결과적으로

**닫기 버튼 클릭**

↓

**click 이벤트 발생**

↓

**함수 실행**

↓

**알림창 `display: none`**

↓

**알림창 사라짐**

순서로 동작한다.

---

**## function()은 무엇일까?**

여기서 처음 보면 조금 이상한 부분이 있다.

```javascript
document.getElementById("close").addEventListener("click", function () {});
```

`function()`이 갑자기 등장한다.

이 `function()`은 **콜백 함수(Callback Function)**라고 부른다.

콜백 함수는 쉽게 말하면

> **다른 함수에게 전달되어 특정 시점에 실행되는 함수**
> **함수 파라미터자리에 들어가는 함수를 전문용어로 '콜백함수'**

라고 생각하면 된다.

---

**## 콜백 함수 이해하기**

먼저 일반적인 함수를 만들어보자.

```javascript
function 인사하기() {
  console.log("안녕하세요");
}
```

그리고 함수를 실행하면

```javascript
인사하기();
```

`"안녕하세요"`가 출력된다.

그런데 `addEventListener()`에서는 함수를 직접 실행하지 않고

함수를 전달한다.

```javascript
addEventListener("click", 인사하기);
```

여기서 중요한 점은

```javascript
인사하기;
```

와

```javascript
인사하기();
```

가 다르다는 것이다.

```javascript
인사하기();
```

는 **지금 바로 실행**한다.

반면

```javascript
인사하기;
```

는 **함수 자체를 전달**한다.

그래서

```javascript
addEventListener("click", 인사하기);
```

라고 하면

> 클릭 이벤트가 발생하면 `인사하기` 함수를 실행해줘

라는 의미가 된다.

---

**## 익명 함수와 콜백 함수**

우리가 작성한 코드를 다시 보자.

```javascript
document.getElementById("close").addEventListener("click", function () {
  document.querySelector(".alert-box").style.display = "none";
});
```

여기서

```javascript
function () {

    document.querySelector(".alert-box").style.display = "none";

}
```

부분이 콜백 함수이다.

이 함수는 이름이 없다.

그래서 **익명 함수(Anonymous Function)**라고도 한다.

즉,

```javascript
function () {

}
```

처럼 이름이 없는 함수를

```javascript
addEventListener();
```

에 전달하고 있다.

그리고 버튼이 클릭되었을 때 이 함수가 실행된다.

---

**## 콜백 함수를 이름 있는 함수로 바꿔보기**

콜백 함수를 따로 만들어서 사용할 수도 있다.

```javascript
function 닫기() {
  document.querySelector(".alert-box").style.display = "none";
}
```

그리고 `addEventListener()`에 전달한다.

```javascript
document.getElementById("close").addEventListener("click", 닫기);
```

이렇게 작성해도 똑같이 동작한다.

전체적인 구조를 보면

```javascript
function 닫기() {
  // 알림창 닫기
}

document.getElementById("close").addEventListener("click", 닫기);
```

이다.

여기서 `닫기` 함수는 클릭 이벤트가 발생했을 때 실행되기 때문에

**콜백 함수로 사용되고 있다.**

---

**## function()과 function 이름()의 차이**

다음 두 코드를 비교해보자.

```javascript
function 닫기() {}
```

이것은 이름이 `닫기`인 함수이다.

반면

```javascript
function () {

}
```

이것은 이름이 없는 **익명 함수**이다.

`addEventListener()`에서는 이런 익명 함수를 바로 전달해서 사용할 수 있다.

```javascript
document.getElementById("close").addEventListener("click", function () {
  document.querySelector(".alert-box").style.display = "none";
});
```

이렇게 하면 굳이 별도의 함수 이름을 만들지 않아도 된다.

**## onclick과 addEventListener 비교**

두 가지 방법 모두 클릭 이벤트를 처리할 수 있다.

### onclick 사용

```html
<button onclick="창버튼('none')">닫기</button>
```

HTML에서 직접 이벤트를 작성한다.

### addEventListener 사용

```html
<button id="close">닫기</button>
```

```javascript
document.getElementById("close").addEventListener("click", function () {
  document.querySelector(".alert-box").style.display = "none";
});
```

HTML과 JavaScript의 역할을 나누어서 작성할 수 있다.

---

**## addEventListener의 기본 문법**

정리하면 `addEventListener()`의 기본 형태는

```javascript
요소.addEventListener("이벤트", 콜백함수);
```

이다.

예를 들어

```javascript
button.addEventListener("click", function () {
  console.log("버튼을 클릭했습니다.");
});
```

라고 작성하면

버튼 클릭

↓

`click` 이벤트 발생

↓

콜백 함수 실행

↓

`"버튼을 클릭했습니다."` 출력

순서로 동작한다.

**## 결론**

JavaScript에서는 `onclick`을 사용하는 방법뿐만 아니라

`addEventListener()`를 이용해서 이벤트를 처리할 수 있다.

```javascript
document.getElementById("close").addEventListener("click", function () {
  document.querySelector(".alert-box").style.display = "none";
});
```

여기서

```javascript
"click";
```

은 **클릭 이벤트**이고

```javascript
function () {

}
```

은 **클릭 이벤트가 발생했을 때 실행되는 콜백 함수**이다.

그리고

```javascript
function () {

}
```

처럼 이름이 없는 함수는 **익명 함수**라고 한다.

정리하면

```text
addEventListener()
        ↓
이벤트를 등록
        ↓
"click"
        ↓
클릭했을 때
        ↓
콜백 함수 실행
```

즉,

> **addEventListener()는 특정 이벤트가 발생했을 때 실행할 함수를 등록하는 방법이고, 그때 전달하는 함수가 콜백 함수이다.**

이번에는 `click` 이벤트만 사용했지만 JavaScript에서는 `mouseover`, `keydown`, `input`, `submit` 등 다양한 이벤트를 `addEventListener()`로 처리할 수 있다.
