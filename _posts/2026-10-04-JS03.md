# JavaScript addEventListener와 콜백 함수

JavaScript에서는 버튼을 클릭했을 때 특정 기능을 실행하거나

마우스를 올렸을 때 동작을 실행하는 등 다양한 **이벤트(Event)**를 처리할 수 있다.

이전에는 HTML의 `onclick` 속성을 사용해서 버튼 클릭 이벤트를 처리했다.

예를 들어

```html
<button onclick="창버튼('none')">닫기</button>
```

처럼 작성할 수 있다.

하지만 JavaScript에서는 HTML에 `onclick`을 직접 작성하지 않고

**`addEventListener()`**를 사용해서 이벤트를 처리할 수도 있다.

이번 글에서는

- `onclick`과 `addEventListener()`의 차이
- `addEventListener()` 기본 문법
- 콜백 함수(Callback Function)
- 익명 함수(Anonymous Function)
- 함수 실행 `()`과 함수 전달의 차이

를 알아보자.

---

## 1. onclick으로 이벤트 처리하기

먼저 이전에 사용했던 `onclick` 방식부터 살펴보자.

```html
<button onclick="창버튼('none')">닫기</button>
```

버튼을 클릭하면 `창버튼()` 함수가 실행된다.

예를 들어 JavaScript를 다음과 같이 작성할 수 있다.

```javascript
function 창버튼(display) {
  document.querySelector(".alert-box").style.display = display;
}
```

버튼을 클릭하면

```javascript
창버튼("none");
```

이 실행되고 알림창이 사라진다.

이 방법도 간단하게 사용할 수 있지만

HTML 코드 안에 JavaScript 코드가 직접 들어가 있다는 특징이 있다.

---

## 2. addEventListener 사용하기

이번에는 `onclick`을 사용하지 않고

JavaScript의 `addEventListener()`를 이용해서 같은 기능을 만들어보자.

먼저 HTML에서 버튼에 `id`를 지정한다.

```html
<div class="alert-box" id="alert">
  <p>알림창임</p>
  <button id="close">닫기</button>
</div>
```

이전처럼

```html
<button onclick="창버튼('none')">닫기</button>
```

라고 작성하는 것이 아니라

```html
<button id="close">닫기</button>
```

처럼 버튼의 `id`만 지정한다.

그리고 JavaScript에서 해당 버튼을 가져온다.

```javascript
document.getElementById("close");
```

이제 이 버튼에 클릭 이벤트를 등록하면 된다.

```javascript
document.getElementById("close").addEventListener("click", function () {});
```

---

## 3. addEventListener()란?

`addEventListener()`는 HTML 요소에 **이벤트를 등록하는 기능**이다.

기본적인 형태는 다음과 같다.

```javascript
요소.addEventListener("이벤트", 실행할함수);
```

예를 들어

```javascript
button.addEventListener("click", function () {});
```

라고 작성할 수 있다.

여기서 `"click"`은 버튼을 클릭했을 때 발생하는 이벤트이다.

즉,

```javascript
addEventListener("click", ...)
```

은 쉽게 말하면

> 이 요소가 클릭되었을 때 뒤에 있는 함수를 실행해줘

라는 의미이다.

---

## 4. 클릭하면 알림창 닫기

이제 실제로 버튼을 클릭했을 때 알림창이 사라지도록 만들어보자.

```javascript
document.getElementById("close").addEventListener("click", function () {
  document.querySelector(".alert-box").style.display = "none";
});
```

코드를 하나씩 살펴보자.

먼저

```javascript
document.getElementById("close");
```

를 이용해서 `id="close"`인 버튼을 가져온다.

그리고

```javascript
.addEventListener("click", ...)
```

을 이용해서 버튼에 `click` 이벤트를 등록한다.

마지막으로

```javascript
document.querySelector(".alert-box").style.display = "none";
```

을 실행해서 알림창을 숨긴다.

전체적인 동작 과정은 다음과 같다.

```text
닫기 버튼 클릭
      ↓
click 이벤트 발생
      ↓
콜백 함수 실행
      ↓
display를 none으로 변경
      ↓
알림창 사라짐
```

---

## 5. addEventListener()의 기본 구조

앞에서 작성한 코드를 조금 더 단순하게 생각해보자.

```javascript
요소.addEventListener("이벤트", 함수);
```

여기서

```text
요소
 ↓
어떤 HTML 요소에 이벤트를 등록할 것인가?

"이벤트"
 ↓
어떤 이벤트가 발생했을 때 실행할 것인가?

함수
 ↓
이벤트가 발생하면 어떤 코드를 실행할 것인가?
```

예를 들어

```javascript
button.addEventListener("click", 함수);
```

라고 하면

> `button`이 클릭되었을 때 `함수`를 실행해줘

라는 의미이다.

---

## 6. function()은 왜 사용하는 걸까?

다음 코드를 보면

```javascript
document.getElementById("close").addEventListener("click", function () {});
```

갑자기 `function()`이 등장한다.

이 `function()`은 **함수**이고,

`addEventListener()`에 전달되는 함수이기 때문에 **콜백 함수(Callback Function)**라고 부른다.

콜백 함수는 쉽게 말하면

> **다른 함수에 전달되어 특정 시점에 실행되는 함수**

라고 생각하면 된다.

즉,

```javascript
addEventListener("click", function () {});
```

에서 `function () {}` 부분이

클릭 이벤트가 발생했을 때 실행할 함수이다.

---

## 7. 콜백 함수(Callback Function)란?

먼저 일반적인 함수를 만들어보자.

```javascript
function 인사하기() {
  console.log("안녕하세요");
}
```

그리고 함수를 실행하면

```javascript
인사하기();
```

콘솔에

```text
안녕하세요
```

가 출력된다.

그런데 `addEventListener()`에서는 함수를 바로 실행하지 않고 **함수 자체를 전달**한다.

```javascript
addEventListener("click", 인사하기);
```

이때 중요한 것이

```javascript
인사하기;
```

와

```javascript
인사하기();
```

의 차이다.

---

## 8. 함수 이름과 함수 실행의 차이

### 함수 실행하기

```javascript
인사하기();
```

`()`를 붙이면 함수를 **지금 바로 실행**한다.

즉,

```text
인사하기()
↓
지금 실행
↓
"안녕하세요" 출력
```

이다.

### 함수 자체 전달하기

반면

```javascript
인사하기;
```

처럼 `()`를 붙이지 않으면 함수 자체를 다른 곳에 전달할 수 있다.

```javascript
addEventListener("click", 인사하기);
```

이렇게 작성하면

> 클릭 이벤트가 발생했을 때 `인사하기` 함수를 실행해줘

라는 의미가 된다.

즉,

```javascript
인사하기();
```

와

```javascript
인사하기;
```

는 다르다.

```text
인사하기()
→ 함수를 지금 실행

인사하기
→ 함수를 전달
```

이 차이는 JavaScript에서 매우 중요하다.

---

## 9. 익명 함수와 콜백 함수

다시 우리가 작성했던 코드를 살펴보자.

```javascript
document.getElementById("close").addEventListener("click", function () {
  document.querySelector(".alert-box").style.display = "none";
});
```

여기서

```javascript
function () {
  document.querySelector(".alert-box").style.display = "none";
}
```

부분이 콜백 함수이다.

그런데 이 함수에는 이름이 없다.

이처럼 이름이 없는 함수를 **익명 함수(Anonymous Function)**라고 한다.

즉,

```javascript
function () {

}
```

처럼 이름이 없는 함수가

`addEventListener()`에 전달되고 있다.

그리고 클릭 이벤트가 발생하면 이 함수가 실행된다.

따라서 이 코드에서는

```text
function () {}
      ↓
이름이 없는 함수
      ↓
익명 함수
      ↓
addEventListener()에 전달
      ↓
클릭하면 실행
      ↓
콜백 함수로 동작
```

한다고 이해하면 된다.

**익명 함수와 콜백 함수는 서로 다른 개념이다.**

- 이름이 없다는 특징 → **익명 함수**
- 다른 함수에 전달되어 나중에 실행된다는 역할 → **콜백 함수**

하나의 함수가 두 가지 특징을 동시에 가질 수도 있다.

---

## 10. 콜백 함수를 이름 있는 함수로 만들어보기

콜백 함수를 꼭 익명 함수로 작성해야 하는 것은 아니다.

함수를 따로 만들어서 `addEventListener()`에 전달할 수도 있다.

먼저 함수를 만든다.

```javascript
function 닫기() {
  document.querySelector(".alert-box").style.display = "none";
}
```

그리고 `addEventListener()`에 전달한다.

```javascript
document.getElementById("close").addEventListener("click", 닫기);
```

이렇게 작성해도 똑같이 동작한다.

전체적인 구조를 보면

```javascript
function 닫기() {
  document.querySelector(".alert-box").style.display = "none";
}

document.getElementById("close").addEventListener("click", 닫기);
```

이다.

여기서 `닫기` 함수는 클릭 이벤트가 발생했을 때 실행되기 때문에

**콜백 함수로 사용되고 있다.**

---

## 11. 익명 함수 vs 이름 있는 함수

두 가지 방법을 비교해보자.

### 익명 함수 사용

```javascript
document.getElementById("close").addEventListener("click", function () {
  document.querySelector(".alert-box").style.display = "none";
});
```

### 이름 있는 함수 사용

```javascript
function 닫기() {
  document.querySelector(".alert-box").style.display = "none";
}

document.getElementById("close").addEventListener("click", 닫기);
```

두 코드 모두 버튼을 클릭하면 알림창을 닫는다.

차이점은 함수를 바로 작성하느냐,

아니면 함수를 따로 만들어서 전달하느냐이다.

간단한 코드라면 익명 함수를 사용해도 되고,

같은 함수를 여러 곳에서 사용하거나 코드가 길어진다면

함수를 따로 만들어 사용하는 것이 관리하기 편할 수 있다.

---

## 12. onclick과 addEventListener 비교

두 방법 모두 클릭 이벤트를 처리할 수 있다.

### onclick 사용

HTML에서 직접 JavaScript를 작성한다.

```html
<button onclick="창버튼('none')">닫기</button>
```

간단하게 사용할 수 있다는 장점이 있다.

하지만 HTML 안에 JavaScript 코드가 들어가게 된다.

### addEventListener() 사용

HTML에서는 요소만 작성한다.

```html
<button id="close">닫기</button>
```

그리고 JavaScript에서 이벤트를 등록한다.

```javascript
document.getElementById("close").addEventListener("click", function () {
  document.querySelector(".alert-box").style.display = "none";
});
```

이렇게 하면 HTML과 JavaScript의 역할을 나누어서 작성할 수 있다.

간단하게 비교하면 다음과 같다.

| 방식                 | 특징                                 |
| -------------------- | ------------------------------------ |
| `onclick`            | HTML에서 이벤트와 실행할 코드를 작성 |
| `addEventListener()` | JavaScript에서 이벤트를 등록         |
| `onclick`            | 간단한 예제에서 사용하기 편함        |
| `addEventListener()` | 이벤트를 관리하고 확장하기 편함      |

## 14. addEventListener()에서 자주 사용하는 이벤트

이번에는 `click` 이벤트를 사용했지만

`addEventListener()`에서는 다양한 이벤트를 사용할 수 있다.

예를 들어

### 클릭

```javascript
button.addEventListener("click", function () {
  console.log("클릭했습니다.");
});
```

### 마우스를 올렸을 때

```javascript
button.addEventListener("mouseover", function () {
  console.log("마우스를 올렸습니다.");
});
```

### 키보드를 눌렀을 때

```javascript
document.addEventListener("keydown", function () {
  console.log("키보드를 눌렀습니다.");
});
```

### 입력할 때

```javascript
input.addEventListener("input", function () {
  console.log("입력했습니다.");
});
```

### 폼을 제출할 때

```javascript
form.addEventListener("submit", function () {
  console.log("제출했습니다.");
});
```

이처럼 이벤트 종류에 따라 다양한 동작을 만들 수 있다.

## 15. addEventListener() 기본 문법 정리

결국 `addEventListener()`의 기본 형태는 다음과 같다.

```javascript
요소.addEventListener("이벤트", 콜백함수);
```

예를 들어

```javascript
button.addEventListener("click", function () {
  console.log("버튼을 클릭했습니다.");
});
```

라고 작성하면

```text
버튼 클릭
   ↓
click 이벤트 발생
   ↓
콜백 함수 실행
   ↓
"버튼을 클릭했습니다." 출력
```

순서로 동작한다.

## 16. 오늘 배운 핵심

이번 글에서 가장 중요한 내용은

**`addEventListener()`와 콜백 함수의 관계**이다.

### addEventListener()

특정 HTML 요소에 이벤트를 등록한다.

```javascript
요소.addEventListener("이벤트", 함수);
```

### 이벤트

어떤 동작이 발생했을 때를 의미한다.

```javascript
"click";
```

→ 클릭했을 때

```javascript
"mouseover";
```

→ 마우스를 올렸을 때

```javascript
"keydown";
```

→ 키보드를 눌렀을 때

### 콜백 함수

이벤트가 발생했을 때 실행할 함수이다.

```javascript
function () {

}
```

또는

```javascript
function 닫기() {}
```

처럼 작성할 수 있다.

## 17. 한 줄 정리

> **`addEventListener()`는 특정 이벤트가 발생했을 때 실행할 함수를 등록하는 방법이고, 이때 전달하는 함수가 콜백 함수이다.**

그리고

```javascript
function () {

}
```

처럼 이름이 없는 함수는 **익명 함수**라고 한다.

따라서 다음 코드를 보면

```javascript
document.getElementById("close").addEventListener("click", function () {
  document.querySelector(".alert-box").style.display = "none";
});
```

이렇게 이해하면 된다.

```text
getElementById()
       ↓
버튼 가져오기
       ↓
addEventListener()
       ↓
이벤트 등록
       ↓
"click"
       ↓
클릭하면
       ↓
콜백 함수 실행
       ↓
알림창 닫기
```

결국 핵심은 다음 한 줄이다.

```javascript
요소.addEventListener("이벤트", 콜백함수);
```

이번에는 `click` 이벤트를 사용했지만 JavaScript에서는

`mouseover`, `keydown`, `input`, `submit` 등 다양한 이벤트를

`addEventListener()`를 이용해서 처리할 수 있다.
