# JavaScript

JavaScript는 웹페이지에서 동작을 만들어주는 언어이다.

예를 들어 버튼을 클릭했을 때 글자가 바뀌거나

글자의 크기, 색상 등을 변경하고 싶을 때 JavaScript를 사용할 수 있다.

**## HTML 요소 가져오기**

먼저 HTML에 요소를 만들어보자.

```html
<h1 id="hello">안녕하세요</h1>
<h1 id="hi">JS초보에요</h1>
```

여기서 `id="hello"`와 `id="hi"`를 사용하면

JavaScript에서 해당 HTML 요소를 가져올 수 있다.

```javascript
document.getElementById("hello");
```

`getElementById()`는 **id를 이용해서 HTML 요소를 가져오는 기능**이다.

# HTML 내용 변경하기

HTML 요소를 가져왔다면 `innerHTML`을 이용해서 내용을 변경할 수 있다.

```javascript
document.getElementById("hello").innerHTML = "안녕";
```

원래 HTML은

```html
<h1 id="hello">안녕하세요</h1>
```

이렇게 되어있지만 JavaScript가 실행되면

```html
<h1 id="hello">안녕</h1>
```

으로 변경된다.

실제 화면에서는

**변경 전**

안녕하세요

**변경 후**

안녕

이렇게 글자가 변경되는 것을 확인할 수 있다.

**## 글자 크기 변경하기**

JavaScript를 이용하면 CSS도 변경할 수 있다.

```javascript
document.getElementById("hello").style.fontSize = "16px";
```

이 코드는 `hello`라는 id를 가진 HTML 요소의

글자 크기를 `16px`로 변경한다.

기본 `<h1>`은 글자가 큰 편인데

JavaScript가 실행되면 다음처럼 작아진다.

**변경 전**

## 안녕

**변경 후**

안녕

즉,

```javascript
.style.fontSize = "16px";
```

를 이용하면 JavaScript로 글자 크기를 변경할 수 있다.

# 다른 HTML 요소도 변경하기

`id="hi"`인 요소도 똑같은 방법으로 변경할 수 있다.

```javascript
document.getElementById("hi").innerHTML = "씹고수";
```

원래는

```html
<h1 id="hi">JS초보에요</h1>
```

였지만 JavaScript가 실행되면

```html
<h1 id="hi">씹고수</h1>
```

로 변경된다.

# 전체 코드

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>

  <body>
    <h1 id="hello">안녕하세요</h1>
    <h1 id="hi">JS초보에요</h1>

    <script>
      document.getElementById("hello").innerHTML = "안녕";
      document.getElementById("hello").style.fontSize = "16px";
      document.getElementById("hi").innerHTML = "씹고수";
    </script>
  </body>
</html>
```

실행하면 최종적으로 화면에는

```text
안녕
씹고수
```

가 나오게 된다.

여기서 `안녕`은 `16px`로 글자 크기가 변경되고

`씹고수`는 `<h1>`의 기본 글자 크기로 표시된다.

**## 결론**

JavaScript로 HTML을 변경하고 싶으면

```javascript
document.getElementById("hello");
```

으로 HTML 요소를 가져오면 된다.

그리고

```javascript
.innerHTML
```

을 사용하면 HTML 내용을 변경할 수 있고,

```javascript
.style.fontSize
```

를 사용하면 글자 크기도 변경할 수 있다.

정리하면

```javascript
document.getElementById("hello").innerHTML = "안녕";
```

→ HTML 내용 변경

```javascript
document.getElementById("hello").style.fontSize = "16px";
```

→ 글자 크기 변경

이런 식으로 **JavaScript를 이용해서 HTML과 CSS를 조작할 수 있다.**
