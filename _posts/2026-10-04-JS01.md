**## JavaScript**

JavaScript는 웹페이지에서 동작을 만들어주는 언어이다.

예를 들어 버튼을 클릭했을 때 글자가 바뀌거나

글자의 크기, 색상 등을 변경하고 싶을 때 JavaScript를 사용할 수 있다.

**## HTML 요소 가져오기**

먼저 HTML에 요소를 만들어보자.

```html
<h1 id="hello">안녕하세요</h1>
<h1 id="hi">JS초보에요</h1>
```

여기서 `id="hello"`와 `id="hi"`를 사용하면

JavaScript에서 해당 HTML 요소를 가져올 수 있다.

```javascript
document.getElementById("hello");
```

`getElementById()`는 말 그대로 **id를 이용해서 HTML 요소를 가져오는 기능**이다.

**## HTML 내용 변경하기**

HTML 요소를 가져왔다면 `innerHTML`을 이용해서 내용을 변경할 수 있다.

```javascript
document.getElementById("hello").innerHTML = "안녕";
```

원래는

```text
안녕하세요
```

라고 되어있었는데

JavaScript가 실행되면

```text
안녕
```

으로 변경된다.

**## 글자 크기 변경하기**

JavaScript를 이용하면 CSS도 변경할 수 있다.

```javascript
document.getElementById("hello").style.fontSize = "16px";
```

`style.fontSize`를 이용하면 글자의 크기를 변경할 수 있다.

즉,

```javascript
요소.style.속성 = "값";
```

형태로 CSS를 변경할 수 있다.

**## 다른 HTML 요소도 변경하기**

`id`가 `hi`인 요소도 똑같은 방법으로 변경할 수 있다.

```javascript
document.getElementById("hi").innerHTML = "씹고수";
```

그러면

```html
<h1 id="hi">JS초보에요</h1>
```

가

```html
<h1 id="hi">씹고수</h1>
```

로 변경된다.

**## 전체 코드**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>

  <body>
    <h1 id="hello">안녕하세요</h1>
    <h1 id="hi">JS초보에요</h1>

    <script>
      document.getElementById("hello").innerHTML = "안녕";
      document.getElementById("hello").style.fontSize = "16px";
      document.getElementById("hi").innerHTML = "씹고수";
    </script>
  </body>
</html>
```

실행하면 HTML의 내용이 JavaScript에 의해 변경된다.

**## 결론**

JavaScript로 HTML을 변경하고 싶으면

```javascript
document.getElementById("id이름");
```

으로 HTML 요소를 가져오면 된다.

그리고

```javascript
.innerHTML
```

을 사용하면 HTML 내용을 변경할 수 있고,

```javascript
.style.fontSize
```

같은 `style`을 사용하면 CSS도 변경할 수 있다.

정리하면

```javascript
document.getElementById("hello").innerHTML = "안녕";
```

```javascript
document.getElementById("hello").style.fontSize = "16px";
```

이런 식으로 **JavaScript를 이용해서 HTML과 CSS를 조작할 수 있다.**
