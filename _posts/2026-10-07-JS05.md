# JavaScript 조건문과 이벤트

오늘은 JavaScript와 jQuery를 이용하여 **조건문과 이벤트를 활용하는 방법**을 공부했다.

이번에는 단순히 `if`문을 사용하는 것뿐만 아니라,

- `if / else if / else`
- `form`의 `submit` 이벤트
- `e.preventDefault()`
- `.val()`
- `this`
- `.length`
- `input` 이벤트
- 함수와 파라미터

등을 이용해서 실제 웹페이지에서 사용할 수 있는 기능을 만들어봤다.

---

# 1. if / else if / else

JavaScript에서 조건에 따라 다른 코드를 실행하고 싶을 때 `if`문을 사용한다.

```javascript
if (조건식) {
  // 조건이 참일 때 실행
} else if (조건식) {
  // 위 조건이 거짓이고
  // 이 조건이 참일 때 실행
} else {
  // 모든 조건이 거짓일 때 실행
}
```

예를 들어 다음과 같이 작성할 수 있다.

```javascript
if (1 == 3) {
  console.log("맞아요");
} else if (1 == 1) {
  console.log("맞아요2");
}
```

`1 == 3`은 거짓이기 때문에 실행되지 않는다.

그 다음 `else if`의 조건인

```javascript
1 == 1;
```

은 참이므로 다음 코드가 실행된다.

```text
맞아요2
```

## else if란?

`else if`는 **앞의 조건이 거짓일 경우 다음 조건을 검사하는 문법**이다.

즉,

```javascript
if (조건1) {
} else if (조건2) {
} else {
}
```

처럼 여러 가지 조건을 순서대로 검사할 수 있다.

# 2. Form 전송 전에 입력값 검사하기

HTML에서 다음과 같은 로그인 폼을 만들었다.

```html
<form action="success.html">
  <div class="my-3">
    <input type="text" class="form-control" id="id" />
  </div>

  <div class="my-3">
    <input type="password" class="form-control" id="pw" />
    <p id="pw-message"></p>
  </div>

  <button type="submit" class="btn btn-primary">전송</button>
  <button type="button" class="btn btn-danger" id="close">닫기</button>
</form>
```

`전송` 버튼을 누르면 원래는

```html
<form action="success.html"></form>
```

에 설정한 `success.html` 페이지로 이동하게 된다.

하지만 입력값을 검사한 후 문제가 있다면 페이지 이동을 막아야 한다.

# 3. submit 이벤트 사용하기

jQuery를 이용하면 form이 제출될 때 실행되는 코드를 만들 수 있다.

```javascript
$("form").on("submit", function (e) {});
```

여기서

```javascript
"submit";
```

은 form이 제출될 때 발생하는 이벤트이다.

그리고

```javascript
function (e)
```

에서 `e`는 이벤트 객체이다.

---

# 4. 입력값 가져오기

jQuery의 `.val()`을 이용하면 input에 입력된 값을 가져올 수 있다.

```javascript
let 아이디 = $("#id").val();
let 비밀번호 = $("#pw").val();
```

예를 들어 아이디 input에

```text
hello
```

를 입력했다면

```javascript
$("#id").val();
```

의 결과는

```text
hello
```

가 된다.

# 5. 입력값이 비어있는지 검사하기

아이디와 비밀번호를 각각 검사해볼 수 있다.

```javascript
if (아이디 != "" && 비밀번호 == "") {
  e.preventDefault();
  alert("비밀번호를 입력하세요.");
}
```

아이디는 입력했지만 비밀번호가 비어 있다면

```text
비밀번호를 입력하세요.
```

라는 알림창이 나타난다.

---

## 아이디만 비어있는 경우

```javascript
else if (아이디 == "" && 비밀번호 != "") {
  e.preventDefault();
  alert("아이디를 입력하세요.");
}
```

비밀번호는 입력했지만 아이디가 비어 있다면 아이디를 입력하라는 메시지를 보여준다.

---

## 둘 다 비어있는 경우

```javascript
else if (아이디 == "" && 비밀번호 == "") {
  e.preventDefault();
  alert("모두 입력해주세요.");
}
```

아이디와 비밀번호가 모두 비어 있다면

```text
모두 입력해주세요.
```

라는 메시지를 보여준다.

# 6. e.preventDefault()

여기서 중요한 문법이 있다.

```javascript
e.preventDefault();
```

이 코드는 **이벤트의 기본 동작을 막아주는 역할**을 한다.

form의 기본 동작은 제출하는 것이다.

```html
<form action="success.html"></form>
```

따라서 `submit` 이벤트가 발생하면 `success.html`로 이동한다.

하지만 입력값이 잘못되었다면 페이지가 이동하면 안 된다.

이때

```javascript
e.preventDefault();
```

를 사용하면 form의 기본 제출 동작을 막을 수 있다.

예를 들어:

```javascript
if (비밀번호 == "") {
  e.preventDefault();
  alert("비밀번호를 입력하세요.");
}
```

이렇게 하면 경고창을 보여준 뒤 페이지가 이동하지 않는다.

---

# 7. 비밀번호 길이 검사하기

JavaScript에서는 문자열의 길이를 확인할 때 `.length`를 사용할 수 있다.

```javascript
let 비밀번호 = $("#pw").val();

console.log(비밀번호.length);
```

예를 들어 비밀번호가

```text
123456
```

이라면

```javascript
비밀번호.length;
```

의 결과는

```text
6
```

이다.

따라서 비밀번호가 7자리보다 짧은지 확인할 수 있다.

```javascript
else if (비밀번호.length <= 6) {
  e.preventDefault();
  alert("비밀번호는 7자리 이상 입력해주세요.");
}
```

---

# 8. 완성된 Form 검사 코드

지금까지 배운 내용을 합치면 다음과 같다.

```javascript
$("form").on("submit", function (e) {
  let 아이디 = $("#id").val();
  let 비밀번호 = $("#pw").val();

  if (아이디 != "" && 비밀번호 == "") {
    e.preventDefault();
    alert("비밀번호를 입력하세요.");
  } else if (아이디 == "" && 비밀번호 != "") {
    e.preventDefault();
    alert("아이디를 입력하세요.");
  } else if (아이디 == "" && 비밀번호 == "") {
    e.preventDefault();
    alert("모두 입력해주세요.");
  } else if (비밀번호.length <= 6) {
    e.preventDefault();
    alert("비밀번호는 7자리 이상 입력해주세요.");
  }
});
```

조건을 정리하면 다음과 같다.

| 아이디 | 비밀번호   | 결과                |
| ------ | ---------- | ------------------- |
| 입력 O | 입력 X     | 비밀번호 입력       |
| 입력 X | 입력 O     | 아이디 입력         |
| 입력 X | 입력 X     | 모두 입력           |
| 입력 O | 6자리 이하 | 비밀번호 7자리 이상 |
| 입력 O | 7자리 이상 | 정상 제출           |

# 9. 함수와 파라미터

함수를 만들 때 외부에서 값을 전달받을 수도 있다.

```javascript
function 삼육구게임(num) {}
```

여기서 `num`은 **파라미터(parameter)**&#xC774;다.

함수를 호출할 때 값을 전달할 수 있다.

```javascript
삼육구게임(3);
삼육구게임(5);
```

그러면 각각

```text
num = 3
num = 5
```

가 된다.

---

# 10. 369 게임 만들기

숫자가 3의 배수인지 확인하는 간단한 369 게임을 만들어봤다.

```javascript
function 삼육구게임(num) {
  if (num % 3 == 0) {
    console.log("박수");
  } else {
    console.log("통과");
  }
}

삼육구게임(3);
삼육구게임(5);
```

여기서 `%`는 **나머지를 구하는 연산자**이다.

예를 들어

```javascript
3 % 3;
```

의 결과는

```text
0
```

이다.

따라서

```javascript
num % 3 == 0;
```

이면 3의 배수라고 판단할 수 있다.

결과:

```text
박수
통과
```

---

# 11. 업그레이드된 369 게임

이번에는 9의 배수라면 `박수 박수`가 나오도록 만들어봤다.

```javascript
function 업글삼육구(num) {
  if (num % 9 == 0) {
    console.log("박수 박수");
  }

  if (num % 3 == 0) {
    console.log("박수");
  } else {
    console.log("통과");
  }
}

업글삼육구(9);
```

여기서 주의할 점이 있다.

현재 코드는 `if`가 **두 개**이기 때문에 9를 입력하면 두 조건이 모두 실행된다.

```text
박수 박수
박수
```

즉,

```javascript
if
if
```

는 각각 독립적으로 검사한다.

반면

```javascript
if
else if
else
```

는 앞의 조건이 참이면 뒤의 조건을 검사하지 않는다.

이 차이를 이해하는 것이 중요하다.

# 12. 시험 합격 여부 판단하기

두 과목의 점수를 받아 합격 여부를 판단하는 함수도 만들어봤다.

```javascript
function 합격했냐(a, b) {
  if (a < 40 || b < 40) {
    console.log("불합격");
  } else if (a + b >= 120) {
    console.log("합격");
  } else {
    console.log("불합격");
  }
}
```

사용할 때는 점수를 전달한다.

```javascript
합격했냐(30, 50);
합격했냐(60, 60);
```

첫 번째는

```text
30 + 50
```

이지만 첫 번째 과목이 40점 미만이기 때문에 불합격이다.

두 번째는

```text
60 + 60 = 120
```

이고 각각 40점 이상이므로 합격이다.

---

# 13. || 연산자

위 코드에서 처음 보는 연산자가 있다.

```javascript
||
```

`||`는 **OR(또는)**&#xB97C; 의미한다.

```javascript
if (a < 40 || b < 40)
```

은

```text
a가 40점 미만이거나
b가 40점 미만이면
```

이라는 의미이다.

둘 중 하나라도 조건을 만족하면 `true`가 된다.

# 14. input 이벤트 사용하기

이번에는 비밀번호를 입력하는 순간마다 글자를 보여주는 기능을 만들어봤다.

```javascript
$("#pw").on("input", function () {});
```

`input` 이벤트는 input의 값이 변경될 때 발생한다.

따라서 사용자가 비밀번호를 입력할 때마다 코드를 실행할 수 있다.

---

# 15. this를 이용해서 현재 요소 가져오기

다음과 같이 작성했다.

```javascript
$("#pw").on("input", function () {
  let 비밀번호 = $(this).val();
});
```

여기서

```javascript
this;
```

는 **현재 이벤트가 발생한 요소**를 의미한다.

현재 이벤트는

```javascript
$("#pw");
```

에서 발생했기 때문에

```javascript
this;
```

는 `#pw` input을 가리킨다.

따라서

```javascript
$(this).val();
```

은 현재 비밀번호 input에 입력된 값을 가져오는 코드이다.

# 16. 비밀번호 입력 상태 보여주기

HTML에서 메시지를 표시할 공간을 만들어두었다.

```html
<p id="pw-message"></p>
```

그리고 JavaScript에서 입력된 비밀번호 길이를 확인한다.

```javascript
$("#pw").on("input", function () {
  let 비밀번호 = $(this).val();

  if (비밀번호.length <= 6) {
    $("#pw-message").text(
      `비밀번호가 ${비밀번호.length}자리밖에 되지 않습니다.`,
    );
  } else {
    $("#pw-message").text("비밀번호가 충분합니다.");
  }
});
```

비밀번호를 입력하면 `.length`를 이용해서 현재 몇 자리인지 확인한다.

예를 들어

```text
123
```

을 입력하면

```text
비밀번호가 3자리밖에 되지 않습니다.
```

가 표시된다.

7자리 이상 입력하면

```text
비밀번호가 충분합니다.
```

가 표시된다.

# 17. 템플릿 리터럴 `${}`

여기서 새롭게 사용한 문법이 있다.

```javascript
`비밀번호가 ${비밀번호.length}자리밖에 되지 않습니다.`;
```

백틱 `` ` `` 안에서는 `${}`를 이용해서 변수나 표현식의 결과를 문자열에 넣을 수 있다.

예를 들어:

```javascript
let 이름 = "철수";

console.log(`안녕하세요 ${이름}님`);
```

결과:

```text
안녕하세요 철수님
```

마찬가지로

```javascript
${비밀번호.length}
```

는 비밀번호의 길이를 문자열 안에 넣어준다.

# 18. 오늘 배운 내용 정리

오늘은 JavaScript의 **조건문과 이벤트를 실제 웹페이지에 적용하는 방법**을 공부했다.

### 조건문

```javascript

```

조건에 따라 서로 다른 코드를 실행할 수 있다.

```javascript
||
```

여러 조건 중 하나라도 참인지 확인할 수 있다.

```javascript
문자열.length;
```

문자열의 길이를 확인할 수 있다.

### Form 이벤트

```javascript
$("form").on("submit", function (e) {});
```

form이 제출될 때 코드를 실행할 수 있다.

### 기본 동작 막기

```javascript
e.preventDefault();
```

form 제출과 같은 기본 동작을 막을 수 있다.

```javascript
$("#pw").on("input", function () {});
```

사용자가 input의 값을 변경할 때마다 코드를 실행할 수 있다.

```javascript
$(this);

```

## 오늘 배운 내용 한눈에 정리

오늘은 JavaScript에서 **조건문과 이벤트를 활용해 입력값을 검사하는 방법**을 공부했다.

- `if / else if / else`를 이용한 조건문
- `&&`, `||`를 이용한 여러 조건 검사
- `.length`를 이용한 문자열 길이 확인
- `submit` 이벤트로 form 제출 제어
- `e.preventDefault()`로 기본 동작 막기
- `input` 이벤트로 실시간 입력값 확인
- `this`를 이용해 현재 요소 가져오기
- `.val()`로 input 값 가져오기
- 함수의 **파라미터**를 이용해 값 전달하기
- `` `${}` ``를 이용한 템플릿 리터럴 사용

특히 오늘은 단순히 문법만 배우는 것이 아니라, **조건문 + 이벤트 + 함수**를 조합해서 실제 웹페이지에서 사용할 수 있는 기능을 만들어봤다.

앞으로도 배운 JavaScript 문법을 하나씩 조합하면서 웹페이지의 다양한 기능을 직접 만들어보자.
